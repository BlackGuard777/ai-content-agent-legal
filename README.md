# AI Content Agent – legal pages

Public pages for the TikTok / Google developer apps.

1. Create a **public** GitHub repo and upload everything here (the `docs/` folder must stay).
2. Repo **Settings → Pages → Source: Deploy from a branch → Branch: main, folder: /docs → Save**.
3. After a minute the pages are live at `https://<your-username>.github.io/<repo-name>/`:
   - Terms of Service URL: `.../terms.html`
   - Privacy Policy URL: `.../privacy.html`
   - (Website URL, if asked: the root address)
